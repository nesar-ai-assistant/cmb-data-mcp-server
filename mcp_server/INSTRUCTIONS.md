CMB Data MCP Server, organised by DATA TIER. Tier 1: Planck PR3 SMICA/Commander maps + masks (fetch_cmb_map, downloaded once and downgraded to nside<=1024; plot_cmb_map); measure_cmb_power_spectrum turns a map into YOUR OWN tier-2 TT spectrum (use the hm1 x hm2 cross). Tier 2: public CMB bandpowers with covariances (Planck PR3, ACT DR6, SPT-3G D1/2018) and lensing bandpowers. Tier 3 (COMPARISON ONLY, never a measurement or prior): published chains (Planck 2018, ACT DR6), the Planck best-fit theory, and compare_with_published_constraints. Build analyses on tiers 1-2 and compare with tier 3 last. Start with list_cmb_datasets; list_cmb_skills for recipes (cmb-tour first, planck-map-to-power-spectrum for tier 1 -> 2). Units: D_ell = ell(ell+1)C_ell/2pi in muK^2; lensing [L(L+1)]^2 C_L^phiphi/2pi. Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. chi2 from Planck/SPT plotting products is diagonal-only (indicative); ACT DR6 and lensing use full covariances. Heavy tools (fetch_cmb_map, measure_cmb_power_spectrum, analyze_chain, compute_lcdm_theory_spectrum) can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
