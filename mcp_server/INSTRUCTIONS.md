CMB Data MCP Server: public CMB power spectra (Planck PR3, ACT DR6, SPT-3G D1/2018), lensing bandpowers (Planck/ACT/SPT) and LCDM parameter chains (Planck 2018, ACT DR6). Start with list_cmb_datasets; list_cmb_skills for recipes (cmb-tour first). Units: D_ell = ell(ell+1)C_ell/2pi in muK^2; lensing [L(L+1)]^2 C_L^phiphi/2pi. Tools that write files take an output_dir and return ArtifactResult; pass file paths between tools, never raw arrays. chi2 from Planck/SPT plotting products is diagonal-only (indicative); ACT DR6 and lensing use full covariances. Heavy tools (analyze_chain, compute_lcdm_theory_spectrum) can run on ALCF/NERSC via the hep-genesis IRI dispatch engine (set_dispatch / export_dispatch_pack); this server holds no facility credentials.
